## 2. Component A — what is decided

**D3D-04 (Source-derived).** **Both prohibitions are adopted**: rewriting — substituting the system's interpretation for
the actor's statement — and anonymising — losing attribution to the actor who reported it.

**D3D-05 (Source-derived).** **Two obligations, stated positively**: preserve the actor's stated rationale faithfully;
preserve attribution to the reporting actor.

**D3D-06 (Source-derived — its character).** "A representation requirement, **not** a validity requirement." What the
requirement governs is the **form and attribution** of the record, not its standing (D3R-08).

**D3D-07 (Calculated — the logical form is conditional on a record existing).** A governs a rationale **that is
recorded**: where one is, it must be faithful and attributed. It is **not** an obligation to record one, so it adds
nothing to GRP-26's statement-bearing region — that region stays ungoverned as to whether a basis must exist (GRP-26;
DQD-07). It constrains what any recorded rationale must be like.

**D3D-08 (Calculated — A is a requirement, and the set grows by one).** An answer of "required" makes A an obligation
(DSC-05, DSC-09). The requirement set therefore now contains a representation constraint that did not previously exist,
and that the conformance map does not list: the map remains at **118** rows because the decision authorises no canonical
capture (D3D-28). Recording this plainly so that "no canonical edit" is not mistaken for "no requirement added".

**D3D-09 (Calculated — what A's subject is, and its known limit).** A's subject is the **recorded rationale** — the
actor's stated basis co-located with the cause (ODC-06), which post-Q-β is also a ground where the cause is report-only
(QBD-06). Where cause and rationale are one artifact, the constraint attaches to the actor's statement within it. The
rationale's separability within the artifact remains **Unestablished** (ODC-15), so the constraint is stated as a
requirement whose precise carrier is not fixed — and no carrier is authorised (ODC-09; D3R-18).

**D3D-10 (Calculated — what A does not do).** It creates no authority, supplies no validity basis, does not make the
record a warrant, and does not amend D-3b (D3D-27). A faithful record of an inadequate reason remains a faithful record
of an inadequate reason (D3R-09).

## 3. Component B — what is decided

**D3D-11 (Source-derived).** **No general requirement that the rationale never be evaluated.** No blanket prohibition
across the four meanings.

**D3D-12 (Source-derived — the four meanings, each answered, none generalised).**

| | Meaning | Decision |
|---|---|---|
| **(i)** | sufficiency as a warrant | the rationale **cannot establish** that the transition was warranted — **ODC-07 already establishes that limitation**; nothing new is added |
| **(ii)** | truth or accuracy | **not prohibited**; a reported claim **may be investigated or checked** |
| **(iii)** | rule compliance | **no such evaluation rule is established** by this decision |
| **(iv)** | scoring, ranking or comparison | **no new authorisation or prohibition** is established |

**D3D-13 (Calculated — (i) adds no new constraint).** The limitation on warrant is ODC-07's, already decided and already
applying (ODC-07; QBD-15). The answer records that it is unaffected, not that it is newly imposed. So the "never" in
"never evaluated" has **no** standalone force: there is no rule that the rationale is unassessable, only the existing
rule that it establishes nothing.

**D3D-14 (Calculated — (ii) states an absence, not a new permission).** "May be investigated or checked" records that no
prohibition exists; investigation was never forbidden, so nothing is newly granted. This matters for the same reason
DQD-13 does: describing a permissive state is not creating a permission, and it is not a mandate to investigate.

**D3D-15 (Source-derived — B's subject: none of the three).** "No new fold constraint, reader prohibition, or
system-enforced check is created." So the answer to R-4 is **none**: not the fold, not the reader, not a check
(D3R-13).

**D3D-16 (Calculated — CLV-28 is not promoted).** CLV-28's constraint — referenced by the transition, never read as the
status — remains an **inference**, not a stated constraint (QBR-22; QBD-16). With B answered "no", nothing converts it;
ODC-07 remains the only owner-level boundary on use.

**D3D-17 (Calculated — (iii) leaves DQ-4 untouched).** No rule-compliance evaluation rule exists, and none was created.
A standard for assessing a basis against a rule would be a validity-side artefact; the predicate remains absent (CEV-24)
and DQ-4 remains open (DQD-12).

**D3D-18 (Calculated — (iv) leaves comparison ungoverned).** No provision authorises or forbids comparing one basis with
another. GRP-35's finding stands: an auditor with grounds and no rule can compare claims only against each other, not
against a standard.
